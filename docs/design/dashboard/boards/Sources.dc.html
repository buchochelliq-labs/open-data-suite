Rule

Unknown evidence ⇒ build

ODS reuses a node only when it can show the node's inputs are unchanged. When the evidence is missing, the answer is build, never a silent reuse.

exactChecksum matches the last successful build.REUSE if equal
timestampLoad time is not newer than the last build.REUSE if older
inferredNot enough to prove unchanged. Shown as inferred.BUILD
unknownNothing to compare. Readers build too.BUILD
