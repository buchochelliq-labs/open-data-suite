customers selects first_name from stg_customers, but that model no longer produces it.

WHY ODS THINKS SO
  • stg_customers changed in this run (sql) and was rebuilt first.
  • Column lineage: stg_customers now outputs given_name, not first_name.
  • customers last built fine in run b6802661, before that change.

  1. Use given_name in customers.sql, or restore first_name in stg_customers.

FAILED compilation error · unknown macro known pattern
orders

dbt couldn't find the macro cents_to_dollars

The model calls a macro that isn't defined in this project or its installed packages, so dbt stopped before running any SQL. Nothing was changed in the warehouse.

WHY ODS THINKS SO
  • The macro isn't in the manifest's macros.
  • packages.yml changed since the last run; dbt_packages/ may be out of date.
WHERE
models/marts/orders.sql:14
WHAT TO TRY
  1. Install packages, then retry.
  2. Or check the name: a macro called cents_to_dollar exists.
dbt deps && ods state retry --failed
What dbt said 
Compilation Error in model orders (models/marts/orders.sql)
  'cents_to_dollars' is undefined. This can happen when calling a macro that does not exist.
